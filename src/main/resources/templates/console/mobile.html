Mobil istemci simülasyonu

Bu sayfa bir mobil uygulama gibi davranır: /api/auth/mobile/** uç noktaları token'ları gövdede döner, istekler Authorization: Bearer ile ve cookie'siz (credentials: 'omit') gider. Tarayıcı oturumunu etkilemez. Token'lar yalnızca bu sayfanın belleğinde durur; sayfa yenilenince kaybolur.

2. Token'lar

Henüz giriş yok.

3. Token işlemleri

  • Eski refresh token: yenilemeden sonraki 5 saniye içinde 409 REFRESH_IN_PROGRESS (paralel istek toleransı). Daha sonra 401 REFRESH_TOKEN_INVALID: zincir kopyalanmış sayılır, oturum kapanır, hesabın o ana kadarki access token'ları iptal edilir. Sonra güncel token da çalışmaz.
  • Çıkış sonrası aynı access token 401 TOKEN_REVOKED alır.

4. Serbest istek (Bearer)

Bearer isteklerde CSRF başlığı gerekmez.
